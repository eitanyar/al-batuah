# על בטוח — סביבת פיתוח מקומית

האתר עובד עכשיו במחשב שלך, לפני שמעלים אותו לאינטרנט.

## איך לפתוח את האתר

1. פתח/י טרמינל ב-WSL.
2. הדבק/י את הפקודות האלו, אחת בכל פעם:

```bash
cd /home/eitanya/al-batuah
npm run dev
```

3. פתח/י בדפדפן את:

```
http://localhost:5173
```

זהו. כל שינוי שתשמור/י ב-`index.html`, `style.css` או `script.js` יתעדכן בדפדפן אוטומטית.

## איך לעצור את האתר

חזור/י לטרמינל שבו רץ האתר ולחץ/י:

```text
Ctrl + C
```

## מהו כל קובץ

- `index.html` — הטקסט והמבנה של האתר.
- `style.css` — הצבעים, העיצוב והמובייל.
- `script.js` — תפריט המובייל, טאבים ואינטראקציות, ושליחת טופס יצירת הקשר.
- `functions/api/contact.js` — Cloudflare Pages Function ששולחת את הטופס דרך Resend.
- `images/` — לוגו ותמונות.
- `test/` — בדיקות בסיסיות כדי לא לשבור את סביבת הפיתוח.

## טופס יצירת הקשר — איך זה עובד

הטופס שולח בקשת `POST` לכתובת `/api/contact`, שם פונקציית Cloudflare Pages (`functions/api/contact.js`) שולחת מייל דרך Resend לכתובת `office@al-batuah.co.il`. יש גם שדה "מלכודת דבורים" (honeypot) חבוי נגד בוטים.

**בדיקה מקומית של הטופס** (כולל הפונקציה, לא רק העיצוב):

```bash
npm run pages:dev
```

זה מריץ שרת מקומי עם Cloudflare Wrangler בכתובת `http://localhost:8788`. בלי `RESEND_API_KEY` הטופס יחזיר שגיאת "השירות אינו מוגדר" — וזה תקין, כי המפתח עדיין לא קיים מקומית.

## מה צריך כדי שהטופס באמת ישלח מיילים בפרודקשן

הפעולות האלו דורשות גישה לחשבונות של הלקוח (Cloudflare, Resend) ולכן לא בוצעו על ידי:

1. ליצור חשבון Resend (אם עוד אין) ולקבל API key.
2. לאמת בחשבון ה-Resend את הדומיין `al-batuah.co.il` (הוספת רשומות DNS מסוג SPF/DKIM שResend נותן).
3. בפרויקט ה-Cloudflare Pages, תחת Settings → Environment variables, להוסיף משתנה סודי בשם `RESEND_API_KEY` עם הערך מ-Resend.
4. לוודא שכתובת השולח בקוד (`functions/api/contact.js`, קבוע `FROM_EMAIL`) תואמת לדומיין המאומת ב-Resend.

## מה נעשה עכשיו

נבצע שינויים קטנים ובטוחים: אתה אומר מה לשנות באתר, ואני משנה, מפעיל את האתר ובודק בדפדפן. לא נעלה דבר ל-Cloudflare עד שתהיה מרוצה מהגרסה המקומית, ועד שחשבון ה-Cloudflare וה-Resend של הלקוח מוכנים.
